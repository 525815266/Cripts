# Cripts

Personal QingLong scripts exported from `/ql/data/scripts`.

## Notes

- Subscription repository folders, logs, caches, databases, sample files, dependency bundles, binary files, local upload helpers, and personal runtime config JSON files are excluded.
- Secrets and personal identifiers were replaced with placeholders such as `<SENSITIVE>`, `<PHONE>`, `<EMAIL>`, `<ACCOUNT>`, `<JWT_TOKEN>`, and `<ID_CARD>`.
- Fill credentials, cookies, tokens, accounts, and private config values through QingLong environment variables or local config before running.
